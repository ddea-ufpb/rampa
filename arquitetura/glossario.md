# Glossário de Negócio - Rampa

- **Relato:** Um registro geolocalizado gerado por um usuário indicando a presença ou ausência de uma estrutura de acessibilidade.
- **Categoria:** Tipificação fixa da acessibilidade relatada (Ex: Rampa, Piso Tátil, Elevador, Banheiro Adaptado).
- **Consumidor:** Ator que acessa a aplicação unicamente para consultar informações no mapa (planejamento ou navegação).
- **Cidadão (Relator):** Ator logado no sistema que submete de forma ativa os formulários de geolocalização.
- **Moderador:** Usuário administrativo com privilégios para aprovar ou rejeitar relatos pendentes antes que sejam expostos ao público geral.
- **Status:** Estado atual do relato no ciclo de vida de moderação (`pendente`, `aprovado`, `rejeitado`).
- **Bounding Box / Raio:** Região delimitadora quadrada ou circular no mapa utilizada para otimizar as consultas espaciais, trazendo apenas os dados próximos à visão atual do usuário.
