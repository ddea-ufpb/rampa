# ADR-0002 Usar PostgreSQL com PostGIS para Persistência

**Status:** aceita
**Contexto:** A feature central do sistema é baseada em localização. O gancho de desempenho estipula "consultas geoespaciais sob volume: o que há acessível perto de mim".
**Opções consideradas:**
*   MongoDB: Suporta GeoJSON, porém consultas espaciais complexas são mais custosas e menos consistentes.
*   PostgreSQL padrão (colunas float `lat` e `lng`): Exigiria cálculo matemático manual de Haversine (distância) na API, destruindo o desempenho sob volume.
*   PostgreSQL + extensão PostGIS: Padrão ouro da indústria, cria índices espaciais nativos.
**Decisão:** Utilizaremos PostgreSQL com a extensão PostGIS habilitada, persistindo coordenadas como tipo `Geometry(Point)`.
**Consequências:** 
*   **(+) boas:** Altíssimo desempenho em cálculos de raio (ex: `ST_DWithin`); escalabilidade garantida.
*   **(-) ruins:** Exige execução customizada via Docker para embutir a extensão.
